# Benchmarks

Each sample lives in its own subfolder so future Russian and English recordings
can be added without mixing files or runs.

The current sample is an owner-approved 120-second Russian-language recording.
Its audio remains at `sample-120s-diary/sample-120s-diary.wav`; integrity metadata
is in `manifest.json` and usage terms are in `DATA_LICENSE.md`.

Human references and model outputs remain private. `transcribe.py` provides the
compatible HTTP runner used to create new local runs.
